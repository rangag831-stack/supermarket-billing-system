# supermarket-billing-system
 manage supermarket products and generate bills 
🛒 Super Market Billing System
📌 Description

A simple Python project used to manage supermarket products and generate customer bills.

💻 Technologies Used
Python
✨ Features
Enter customer name
Display available products and prices
Select products and enter quantities
Calculate total bill amount
Calculate 18% GST
Generate final bill
Display thank you message
⚙️ Concepts Used
Variables
Input and Output
Lists
Dictionaries
While Loop
If-Else Conditions
Break Statement
Type Conversion
String Methods
Arithmetic Operators
▶️ How to Run
Install Python.
Download or clone this repository.
Open the project in VS Code.
Run the Python file.
bash
python supermarket.py

🎯 Output

The system displays the customer name, purchased items, quantity, total amount, GST, and final bill.
